# QSVT — polynomial spectral filters for the segment Hamiltonian

Can a QSVT polynomial $p(A)$ map the segment-solver failure modes to ~0 where the
1BQF's single cosine notch cannot? Study layout:

## `Initial/` — the feasibility study + first circuit build
Steps A–E (spectral census, polynomial design, classical efficacy, quantum cost,
noise robustness) and the first circuit-level build
(`lhcb_velo_toy.solvers.quantum.QSVT`, LCU-of-Chebyshev over the qubitization
walk; the 1BQF cosine is its degree-1 member), run locally at T = 0–100.
Headline: AUC 0.64 → 0.88 over the 1BQF on the T=200 cluster sample; width is
cheap (29 qubits at T=1000); same-length P4 bridges are the provable floor.
Filter used there: the contiguous **band**-limited inverse.

## `qsvt_store_campaign.py` — the store campaign (production data)
Mirrors the fixed-ε (2 mrad) 1BQF campaign of `Verify_new_results` in the
qtrk_store as **solver='qsvt'**: γ ∈ {1,2,3} × hit_ineff ∈ {0, 0.01} ×
n_trk ∈ {10…400} × 3 reps (108 solves, same events/Hamiltonians/sol-key scheme;
metrics recomputed into the standard view with the classical-partner signal
rescale). Re-runnable; `--overwrite` re-solves existing keys.
Pipeline additions: `qp.solve_qsvt`, `sol_key(..., solver='qsvt')`.

**Production filter = the γ-aware line-comb inverse**
(`design_line_comb_inverse`): narrow ~1/λ passes at the four P4 true-track
eigenvalue lines $s-2\cos(k\pi/5)$, $s=\gamma+\delta$, ~0 elsewhere.
The Initial band design fails at high density — tangles fill the band
(ρ(C)→2.9 at T=400) and its full-event false rate explodes (5.2 % @ T=100 →
43.6 % @ T=400). The comb passes only the geometry-pinned lines: false rate ~0
at every T with ~98–100 % efficiency.

NOTE: `manifest/solutions.csv` is regenerated by `qp.build_manifest` from study
specs — a manifest rebuild drops the qsvt rows (the .npz solutions stay);
re-run the campaign script to re-register them.

## `Segment_level_studies/` — the segment-level analysis, three solvers
Repeats the Toy_Characterisation/Segment_level_studies analysis with QSVT added:
- `01_qsvt_segment_efficiency.ipynb` — the 2×2 (efficiency / false rate /
  pair counts / active counts) vs n_trk, classical + 1BQF + QSVT overlaid;
  γ=3 headline (clean & 1 % drop) + γ ∈ {1,2,3} companion.
- `02_qsvt_amplitudes_and_angles.ipynb` — amplitude histograms (true vs false)
  and active-segment polar angles for the three solvers.

Headline (γ=3, clean): QSVT holds ~98–100 % efficiency at every multiplicity
(no 1BQF endpoint halving, which costs the cosine ~25 % of true segments at
τ) with false rate ≈ 0 through T=400 (classical reaches 2.3 %).
